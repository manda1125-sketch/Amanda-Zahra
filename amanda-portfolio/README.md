# Website Profil Amanda Zahra A.N.

Website profil pribadi sederhana menggunakan HTML, CSS, dan JavaScript.

## Isi folder
- `index.html` — struktur dan konten website
- `style.css` — tampilan dan desain responsif
- `script.js` — tahun otomatis pada footer
- `assets/amanda.jpg` — foto profil

## Cara publikasi melalui GitHub Pages
1. Login ke GitHub dan buat repository baru bernama `amanda-zahra`.
2. Atur repository menjadi **Public**.
3. Upload seluruh isi folder ini (bukan folder ZIP-nya). Pastikan `index.html` berada di bagian utama/root repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
7. Tunggu proses publikasi selesai. URL biasanya berbentuk `https://USERNAME.github.io/amanda-zahra/`.

Ganti `USERNAME` dengan username GitHub milikmu. Uji URL dalam jendela browser privat untuk memastikan halaman dapat dibuka tanpa login.
